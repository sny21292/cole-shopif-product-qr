⚙ HOW IT WORKS
  1. 1
    Video URL Set in Shopify
    The custom.install_video_url metafield is populated on each product variant via CSV import (Matrixify).
  2. 2
    Warehouse Prints Packing Slip
    ShipStation's packing slip template includes <img src="qr.turnoffroad.com/qr?sku=[Sku]"> per line item.
  3. 3
    QR Generated On-the-fly
    This service looks up the variant by SKU, reads the install video URL, and returns a 600x600 PNG QR code with Level H error correction.
  4. 4
    Customer Scans & Watches
    Customer opens the box, scans the QR code, and is taken directly to the install video for that specific product.
